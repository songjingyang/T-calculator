# A 股做 T 成本计算器

专业的 A 股做 T（日内交易）成本计算工具，支持多家券商费率，精确计算交易成本、盈亏和收益率。

## 功能特点

- ✅ **精确费率计算** - 支持主流券商费率，包含佣金、印花税、过户费等
- ✅ **实时计算** - 输入交易信息即时显示盈亏和收益率
- ✅ **交易记录** - 保存交易历史，支持统计分析
- ✅ **响应式设计** - 完美支持手机、平板和桌面设备
- ✅ **深色主题** - 支持浅色/深色主题切换
- ✅ **数据持久化** - 本地存储交易记录和用户偏好

## 技术栈

- **框架**: Next.js 15 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **状态管理**: Zustand
- **表单处理**: React Hook Form + Zod
- **图标**: Lucide React

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看应用。

### 构建生产版本

```bash
npm run build
```

### 启动生产服务器

```bash
npm start
```

## 使用说明

1. **选择券商** - 从下拉菜单中选择您的券商
2. **输入交易信息** - 填写股票代码、买入价格、卖出价格和交易数量
3. **查看计算结果** - 系统会实时显示盈亏和收益率
4. **保存交易记录** - 点击"添加交易记录"保存到历史记录
5. **查看统计** - 在统计面板查看整体交易表现

## 费率说明

### 佣金

- 各券商费率不同，一般为万分之 2.5-3.0
- 最低收费 5 元

### 印花税

- 千分之 1，仅卖出时收取

### 过户费

- 万分之 0.2，买卖双向收取

### 规费

- 万分之 0.2，买卖双向收取
